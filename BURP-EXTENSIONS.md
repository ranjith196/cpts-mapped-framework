# Useful Burp Suite Extensions for CPTS / Web Testing

## Essential / Highly Recommended
- **Logger++** – Better logging and filtering
- **Autorize** – Authorization / IDOR testing helper
- **AuthMatrix** – Multi-user authorization testing
- **Param Miner** – Hidden parameter discovery
- **Turbo Intruder** – Fast custom attacks
- **Active Scan++** – Extra active scan checks
- **J2EEScan** – Java specific checks
- **Software Vulnerability Scanner** – Additional checks

## Useful for Specific Areas
- **Upload Scanner** – File upload testing
- **CORS** related extensions
- **JWT Editor** / **JSON Web Tokens** – JWT testing
- **GraphQL Raider** or similar – GraphQL testing
- **Retire.js** – Outdated JS library detection
- **Backslash Powered Scanner** – Interesting input handling

## Workflow Tips
1. Use a clean project per engagement.
2. Enable Autorize / AuthMatrix early when testing access control.
3. Use Param Miner on interesting requests.
4. Keep Logger++ for evidence collection.

Update this list as you discover better extensions.
