# 03 - Attacking Common Applications & Services

**Original GitBook sections**:
- Attacking Common Applications
- Attacking Common Services

## Major Targets Covered in Notes
- CMS: WordPress, Joomla, Drupal
- Servlet / Dev tools: Tomcat, Jenkins
- Monitoring: Splunk, PRTG
- Others: GitLab, osTicket, CGI / Shellshock, Thick clients

## Checklist Approach
1. Identify the application/service version
2. Look for default credentials
3. Check for known CVEs / public exploits
4. Enumerate users, plugins, themes, or modules
5. Test authentication and authorization
6. Look for file upload, RCE, or information disclosure paths

Always cross-reference the detailed sub-pages in the original GitBook for specific commands.
