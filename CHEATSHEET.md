# CPTS Quick Cheatsheet

## Quick Phase Order
1. Enumerate
2. Nmap deep
3. Common services/apps
4. Web attacks
5. AD (if present)
6. Privesc
7. Pivot / move
8. Document everything

## Essential Mindset
- Understand before you exploit
- Return to enumeration when stuck
- Document as you go
- Chain findings
- Stay in scope
