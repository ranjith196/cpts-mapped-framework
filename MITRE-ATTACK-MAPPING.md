# MITRE ATT&CK Mapping (CPTS Focused)

High-level mapping of common CPTS / pentest activities to MITRE ATT&CK techniques (Enterprise).

## Reconnaissance
- T1595 – Active Scanning
- T1592 – Gather Victim Host Information
- T1590 – Gather Victim Network Information

## Initial Access / Execution
- T1190 – Exploit Public-Facing Application
- T1133 – External Remote Services
- T1059 – Command and Scripting Interpreter

## Persistence / Privilege Escalation
- T1078 – Valid Accounts
- T1548 – Abuse Elevation Control Mechanism
- T1068 – Exploitation for Privilege Escalation

## Defense Evasion / Credential Access
- T1110 – Brute Force
- T1550 – Use Alternate Authentication Material
- T1003 – OS Credential Dumping (lab context)

## Discovery / Lateral Movement
- T1087 – Account Discovery
- T1018 – Remote System Discovery
- T1021 – Remote Services
- T1570 – Lateral Tool Transfer

## Collection / Exfiltration / Impact
- T1005 – Data from Local System
- T1041 – Exfiltration Over C2 Channel (lab)

> Use this as a reference when writing professional reports. Map your findings to ATT&CK where it adds clarity for the client.
